for updating table entries there are 2 ways:

  1. PUT: completly rewrites table entry (you need to add all fields that the table needs)
  2. PATCH: can update any column that you specify
Example:
DB: 
{
"id": 1,
"name": "John Doe",
"email": "john.doe@google.com"
}
PUT: 
PUT: /api/user/1
{
"name": "Jane Doe", //change name
"email": "john.doe@google.com" //you need to specify all fields
//if you don't include "email", "email" will be set to null
}
is the same as
PATCH: 
PATCH: /api/user/1
{
"name": "Jane Doe", //change name
//you can specify only changing fields
}
